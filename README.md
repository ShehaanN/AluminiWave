#  AluminiWave – Alumni Engagement and Management System  

AluminiWave is a **web-based platform** designed to empower universities and educational institutions with modern tools to **manage alumni networks effectively**. The system integrates **real-time communication, job sharing, event management, mentorship**.  

---

## 🚀 Features  

- 🔑 **Authentication & Authorization** – Secure login/registration with **Supabase Auth**  
- 🖥️ **Role-Based Dashboards** – Separate views for Students, Alumni, Organizers, and Admins  
- 💬 **Real-Time Chat** – Powered by **Supabase Realtime**  
- 🎉 **Event Management** – Create, join, and manage alumni/university events with file upload support  
- 💼 **Job Portal** – Alumni can post jobs; students can explore opportunities  
- 🧑‍🏫 **Mentorship Module** – Request mentorship, schedule sessions, and chat with alumni  
- 🤖 **Recommendations** – Personalized mentor, job, and event suggestions  
- 📊 **Admin Analytics Dashboard** – Monitor engagement, activities, and reports  

---

## 🛠️ Tech Stack  

### **Frontend**
- React + Vite ⚡  
- Tailwind CSS 🎨  
- ShadCN/UI (Reusable Components)  
- React Router DOM  

### **Backend (BaaS with Supabase)**
- PostgreSQL (Database)  
- Supabase Auth (Authentication & RLS Policies)  
- Supabase Storage (Resumes, Banners, Media)  
- Supabase Realtime (Chat & Updates)  
- Supabase Edge Functions (Logic & Business Rules)  
- PostgREST (Auto-generated APIs)  

---

## 📂 Project Modules  

- 👤 **User Management** – Registration, profiles, role-specific access  
- 📅 **Event Creation & Participation** – End-to-end lifecycle management  
- 💼 **Job Sharing** – Alumni-driven job postings with student access  
- 🧑‍🏫 **Mentorship System** – Matchmaking, scheduling, and recommendations
